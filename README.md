# Coffee Shop Sales Analysis ☕📊

## Project Overview

This project provides a comprehensive analysis of coffee shop sales data. The goal of this analysis is to uncover key business insights, track performance metrics, and understand customer purchasing patterns to drive data-informed decision-making.

The entire analysis and dashboard were built using Microsoft Excel, demonstrating advanced data manipulation and visualization techniques.

## The Data

The primary dataset and analysis are contained within the following file:

* **`Coffee Shop Sales project main.xlsx`**

*The dataset includes daily transaction records, product categories, and store locations for the year 2023.*

## Tools & Techniques Used

This project leverages advanced Excel functionalities to transform raw data into an interactive dashboard:

* **Microsoft Excel**: For data cleaning, processing, and visualization.

* **Pivot Tables**: Used extensively to aggregate sales data, summarize revenue by product categories, and analyze time-series trends.

* **KPIs (Key Performance Indicators)**: Custom metrics formulated to track business health, such as Total Revenue, Average Order Value, and Total Orders.

* **Slicers**: Integrated to provide interactive filtering, allowing users to slice the data by specific dates, store locations, or product types dynamically.

## Key Insights & Findings

1. **Peak Sales Hours:** The majority of transactions occur between 8:00 AM and 10:00 AM.

2. **Top Performing Product:** Chocolate Croissant  generated the highest total revenue across all store locations.

3. **Seasonal Trends:** A noticeable spike in sales was observed during the winter months, driven by seasonal holiday beverages.

## How to Use This Project

1. Download the `Coffee Shop Sales project main.xlsx` file from this repository.

2. Open the file in Microsoft Excel (version 2016 or newer recommended for full Slicer functionality).

3. Navigate to the "Dashboard" tab (or equivalent) to interact with the visualizations.

4. Use the provided Slicers to filter the metrics by different dimensions and explore the data.
